# Block Survivor — أونلاين (تعاوني حتى 4 لاعبين)

تعديل على اللعبة الأصلية بحيث:
- **لعب فردي أوفلاين** يفضل شغال بالضبط زي ما كان (مفيش أي تعديل عليه).
- **لعب أونلاين حقيقي** (WebSocket عبر Socket.io) فردي أو مع فريق حتى 4 لاعبين، بسيرفر تستضيفه إنت بنفسك.

## اللي هتلاقيه هنا
```
server/   → سيرفر Node.js (Express + Socket.io) هو اللي بيشغل اللعبة فعليًا (authoritative)
client/   → index.html بتاع اللعبة (نفس الملف الأصلي + شاشات أونلاين جديدة)
```

## المميزات المطبّقة
- **حساب بسيط بالاسم فقط** (من غير باسورد) — أول مرة بتسجل باسم معين بيتحفظله توكن على جهازك تلقائيًا عشان ترجعله من نفس الجهاز.
- **أصدقاء**: تبعت طلب صداقة بالاسم، تقبل/ترفض، وتشوف مين أونلاين دلوقتي.
- **فريق (غرفة) بكود قصير** (5 حروف) — تعمل غرفة وتحدد حجم الفريق (2-4)، تدعي أصحابك مباشرة (Add Team) أو تدّيهم الكود يدخلوا بيه، وفيه زر "جاهز" لكل واحد والمضيف بس اللي يضغط "ابدأ".
- **تصويت جماعي على الكروت**: أي حد وصل الفريق لمستوى جديد، بتظهر 3 كروت للكل، كل لاعب يصوّت **مرة واحدة بس** (الزرار بيتقفل بعد ما تختار)، فيه عداد 20 ثانية (قابل للتغيير)، ولو كل اللاعبين صوّتوا قبل الوقت بيتحسم فورًا. الكرت اللي ياخد أكتر أصوات بياخده **كل الفريق**.
- **الوحوش بتوزّع هجومها**: كل وحش بيختار أقرب لاعب ليه، مع ميل إنه يتجنب اللاعب اللي عليه وحوش كتير أصلاً (عشان الهجوم يتوزع على الفريق مش يركز على واحد بس)، وبيعيد اختيار الهدف كل شوية.
- **الصعوبة بتزيد مع حجم الفريق**: عدد الوحوش، الداتم، والدم بتاعهم كله بيتحسب بناءً على عدد اللاعبين المتصلين فعليًا.
- لو الفريق كله مات، اللعبة تخلص (Game Over) والمضيف يقدر يعمل "ابدأ من جديد" يرجع الكل للوبي.

## حدود مهمة لازم تعرفها
- الاتصال حقيقي (WebSocket) لكن **السيرفر هو اللي بيحسب كل حاجة** ويبعت للعبين اللي بيحصل (حركة/هجوم/وحوش) بمعدل 20 مرة/ثانية عشان اللعب يبان سلس. ده معناه إن فيه تأخير بسيط (latency) حسب سرعة النت والمسافة من السيرفر، زي أي لعبة أونلاين حقيقية.
- التأثيرات البصرية الصغيرة (شرر/ضربات) بتتولّد عند كل جهاز لوحده من نفس الأحداث، فمش هتتطابق بكسل بكسل بين اللاعبين، لكن ده تجميلي بحت ومالوش أي تأثير على نتيجة اللعبة.
- الفريق بياخد XP ومستوى **مشترك** (مش كل لاعب لوحده) عشان نظام التصويت الجماعي يبقى له معنى — كل واحد لسه عنده HP بتاعه لوحده.

## تشغيل السيرفر (على جهازك أو أي استضافة)
يحتاج **Node.js 18 أو أحدث**.

```bash
cd server
npm install
npm start
```

هيشتغل افتراضيًا على المنفذ `3000`، وهيوصّل ملفات `client/` تلقائيًا كمان (يعني تقدر تفتح `http://localhost:3000` في المتصفح تلاقي اللعبة شغالة، من غير ما تحتاج تفتح ملف `client/index.html` بشكل منفصل).

يمكنك تغيير المنفذ أو مدة التصويت بمتغيرات بيئة:
```bash
PORT=8080 VOTE_SECONDS=15 npm start
```

## رفع السيرفر على استضافة حقيقية (عشان يشتغل مع أصحابك من أي مكان)
أي استضافة بتدعم Node.js + WebSocket زي **Render** أو **Railway** أو **Fly.io** تقدر تستخدمها:
1. ارفع فولدر `server/` على مستودع Git.
2. من إعدادات الاستضافة: Build command = `npm install`, Start command = `npm start`.
3. هياخدلك رابط زي `https://your-app.onrender.com`.
4. لو هتفتح `client/index.html` منفصل (مش من نفس السيرفر)، هيظهرلك في شاشة تسجيل الدخول حقل صغير "السيرفر" — حط فيه نفس الرابط بتاع الاستضافة.

## ملاحظة عن Solo
وضع "لعب فردي أوفلاين" في القائمة الرئيسية بيشتغل بنفس الكود الأصلي بالظبط من غير سيرفر خالص — تقدر تفتح `client/index.html` من جهازك مباشرة وتلعب بيه من غير ما تشغل أي سيرفر.
